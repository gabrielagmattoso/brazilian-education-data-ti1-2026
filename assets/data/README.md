# Dados do projeto

Este diretório reúne a documentação dos arquivos utilizados na coleta, preparação e integração dos dados.

## Arquivos esperados

| Arquivo | Conteúdo |
|---|---|
| `Tabela_Escola_2025.csv` | Atributos institucionais das escolas. |
| `Tabela_Matricula_2025.csv` | Quantitativo de matrículas no Ensino Médio regular. |
| `tx_rend_escolas_2024.xlsx` | Taxa oficial de abandono do Ensino Médio por escola, utilizada como variável-alvo. |
| `base_final.csv` | Base final processada, limpa e selecionada, conforme a documentação original do projeto. |

## Fontes oficiais

As bases do Censo Escolar, cujo volume pode ultrapassar 25 MB, estão disponíveis no portal do Inep:

- [Microdados do Censo Escolar](https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados/censo-escolar)

As Taxas de Rendimento Escolar de 2024 podem ser consultadas por escola:

- [Taxas de Rendimento Escolar — Inep](https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/indicadores-educacionais/taxas-de-rendimento-escolar)

**Observação:** os arquivos de dados listados acima não estão armazenados atualmente neste diretório do repositório. Esta página documenta os arquivos esperados e suas fontes; não substitui as bases originais.
